## Verwendung

1. ZIP entpacken und die Ordnerstruktur (besonders `assets/`) beibehalten.
2. In VS Code mit **Strg + Umschalt + V** die Markdown-Vorschau öffnen.
3. Auf GitHub Pages die Markdown-Dateien in das gewünschte Webseitendesign integrieren. Markdown allein ist noch kein fertiges Website-Layout.
4. Bilder sind bereits über **relative Pfade** aus dem Lernartikel referenziert.
5. Bei einer späteren Veröffentlichung keine echten Benutzerkonten, E-Mail-Inhalte oder vertraulichen Exchange-Logs verwenden.
