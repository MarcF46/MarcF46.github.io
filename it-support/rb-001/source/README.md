# RB-001 – Übernahme in die GitHub-Webpräsenz

Dieses Paket enthält die technische Runbook-Fassung für Supportfall 01, inklusive der drei bereits erstellten Illustrationen.

- `RB-001_Windows-Anmeldung.md` – fertiger Runbook-Entwurf mit 15 Abschnitten, kommentierten PowerShell-Beispielen, Quellen und Lernkontrolle.
- `assets/identitaetsinfrastruktur_ueberblick.png` – Überblicksgrafik.
- `assets/identitaetsinfrastruktur_details.png` – erweiterte Identitätsinfrastruktur mit Kerberos/NTLM.
- `assets/vpn_henne_ei.png` – Pre-Logon-VPN als Henne-Ei-Problem.

## Veröffentlichungshinweise

1. Die drei relativen Bildverweise sind bereits im Markdown eingebaut. Pfade bei GitHub Pages gegebenenfalls an die tatsächliche Site-Struktur anpassen.
2. Das Mermaid-Diagramm muss für die eingesetzte GitHub-Pages-Technik auf korrekte Darstellung geprüft oder später als SVG eingebunden werden.
3. Der Text kennzeichnet alle Beispiel-Tickets und Diagnoseergebnisse als konstruiert. „Praktisch validiert“ erst nach eigenem Test ändern.
4. Personen-, Kunden- und Zugangsdaten niemals aus echten Tickets ungeprüft veröffentlichen.
5. Abbildungen: „Eigene Konzeption, KI-gestützte Visualisierung mit ChatGPT“.
